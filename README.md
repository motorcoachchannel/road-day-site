# Road Day

Official website for **Road Day**, the Motorcoach Channel's traveling flagship show.

> Wherever the industry is moving, we're there.

## What's here
- `index.html`: the one-page site (ticker, countdown, episodes, route map, rundown, the Coach Set, the opening, Host the Show form)
- `style.css`, `app.js`: styles and interactions
- `assets/`: images, logos, fonts, map data and the opening video

## Hosting
This is a plain static site with no build step. It deploys on Render as a static site with publish path `./`. Every push to `main` goes live automatically.
